# Богдан Матвеев — личный сайт

Статический сайт о пошиве одежды, маркетплейсах и сервисе «СеллерШьет».

Все изображения, шрифты и иконки находятся в `dist/`. Сборка и установка зависимостей не нужны. Сайт не собирает заявки и персональные данные.

## Railway

Подключённая ветка: `main`. Dockerfile запускает сервер на порту Railway (`PORT`, локально по умолчанию 8080). Проверка работоспособности: `/`.

## Локальный запуск

```sh
python3 -m http.server 8080 --directory dist
```

## Изменения

Тексты, стили и сценарий находятся в `dist/index.html`. Изображения — в `dist/images/`. Коммит в `main` запускает новое развёртывание Railway.

Лицензии шрифтов и иконок сохранены рядом с соответствующими файлами.
